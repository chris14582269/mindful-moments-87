# Security and PDPA Notes

This repository implements technical safeguards that support Singapore PDPA and healthcare-grade practices, but production launch still requires legal, clinical, and security review.

## Implemented controls

- Consent timestamp on user registration.
- JWT authentication and role-based authorization.
- Audit log table for sensitive events.
- Environment-variable configuration for secrets.
- S3 server-side encryption and Terraform KMS resources.
- OpenAPI documentation generated by FastAPI.

## Operational requirements

- Define retention periods for meal images, chat records, and audit events.
- Provide data access/export/deletion workflows for PDPA requests.
- Run threat modelling for WhatsApp webhooks and clinical dashboards.
- Conduct penetration testing before onboarding patients.
- Keep OpenAI and Meta data processing agreements current.
